# FastAPI + AI Models


> Python >= 3.13.4

## Installation

```bash
    # Create an isolated environment
    python3 -m venv ./.venv

    # Activate env
    source ./.venv/bin/activate # Linux/MacOS
    deactivate # Just in case you need to deactivate the env

    # Install Python dependencies
    pip3 install -r requirements.txt

    # Run the application
    fastapi dev main.py
```
